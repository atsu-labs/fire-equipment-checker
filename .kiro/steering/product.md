# Product Overview

消防法施行令別表第一に基づき、建築物の用途・規模から必要な消防用設備を自動判別するWebアプリケーション。消防職員(査察、事前協議、適合調査、指導文書作成)が対象ユーザー。

## Core Capabilities

1. **規制自動判別**: 建築物情報(用途、延床面積、階数等)入力により、消防法令に基づく必要設備を自動算出
2. **法令根拠付きレポート**: 適用された条文・項・号を明示した判定結果の出力
3. **複雑ルール対応**: 47用途コード × 面積・階数条件 × 14種類の消防設備の組み合わせロジック
4. **PDF出力**: 査察・協議・指導に利用可能な公式レポート生成

## Target Use Cases

- **事前協議**: 建築計画段階での必要設備の確認
- **査察業務**: 既存建築物の法令適合性チェック
- **適合調査**: 用途変更時の設備要件確認
- **指導文書作成**: 根拠条文を含む指導書の作成支援

## Value Proposition

消防法施行令の複雑な条件分岐(用途別・面積別・階数別)を自動化し、法令解釈の属人化・判定ミスを防止。手動計算・Excel管理から脱却し、根拠付き判定を秒単位で提供。
